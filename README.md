## Description

This repository contains my COAL assignments, laboratory
tasks, and practice programs written in 8088 Assembly Language.

Programs cover:
- Registers and memory operations
- Stack operations
- Procedures and subroutines
- String instructions
- Video memory (0xB800)
- Screen handling and graphics
- Loops and conditional jumps
- Windowed scrolling and keyword highlighting

## Tools Used

- NASM (Netwide Assembler)
- DOSBox
- 8088 Assembly Language

## How to Assemble and Run

1. Open DOSBox.
2. Navigate to the directory containing the assembly file.
3. Assemble using NASM:

```bash
nasm filename.asm -o filename.com
```

4. Run the generated COM file:

```bash
filename.com
```
